    Open gauge records (ADHI)
    
      
    Monthly discharge for 1,466 African gauging stations from the African Database of Hydrometric Indices (Tramblay et al., 2021, CC BY 4.0). Downloaded once, about 7 MB. Stations inside this basin are matched to the model's rivers by location and catchment area.
    
      
      
    
      
    
      
    Observed discharge from a file
    
      
    Add gauge records to compare with the model and calibrate. Use a CSV with a date column (YYYY-MM or YYYY-MM-DD) and one column per gauge named as in the gauge list, in m³/s, or a GRDC export file for one station. Daily values are averaged to months.
